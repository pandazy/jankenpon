# jankenpon

This repo holds skills for AI agents. Each skill is a folder in `skills/`:

- **coding-principles**: Write code in the simplest way that works, and follow the style the project already uses.
- **coupling-cohesion-review**: Rate how much the parts of the code depend on each other and how well each part keeps to one job, then suggest fixes.
- **crystal-clear**: Write answers in plain words so any reader understands them the first time.
- **evidence-driven-reasoning**: Support every conclusion with evidence, and check its weak points before anyone acts on it.
- **github-dev-squad**: Plan, build, test and open a pull request for a GitHub task with a team of agents, and get a person's approval at each step.
- **logic-gap-review**: Find bugs in the cases the code does not handle, and give an input that triggers each bug.
- **performance-review**: Find what makes the code slow or use too much memory, rank each problem, and show the code that causes it.
